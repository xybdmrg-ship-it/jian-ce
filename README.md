# jian-ce
基于《资治通鉴》《史记》的历史决策推演 Skill｜检索结构相似案例，拆解决策、结果与隐性代价

# 鉴策

基于《资治通鉴》《史记》的历史决策推演 Skill。

它会根据用户提出的现实决策问题，
寻找“场景内核相似”的历史案例，并拆解：

- 当时有哪些选项
- 当事人如何判断
- 最终结果
- 显性代价
- 隐性代价
- 对现实决策的启发
- 风险提醒

## 适合什么问题？

例如：

- 我应该继续稳定工作，还是转向高风险高成长方向？
- 面对合作伙伴失信，要继续合作还是及时退出？
- 一个机会看起来很好，但我要付出的隐性成本是什么？

## 使用方式

下载本仓库中的 Skill 文件，
导入支持 Skill 的 AI 环境后使用。
