# 指定古籍库与证据纪律

## 指定来源

### 主检索库：中文维基文库逐卷原文

- 《史记》总目录：<https://zh.wikisource.org/zh-hans/史記>
- 《资治通鉴》总目录：<https://zh.wikisource.org/zh-hans/資治通鑑>
- 《史记》逐卷格式：`https://zh.wikisource.org/zh-hans/史記/卷NNN`
- 《资治通鉴》逐卷格式：`https://zh.wikisource.org/zh-hans/資治通鑑/卷NNN`

优先引用逐卷页，不引用搜索结果页、百科词条或二手故事页。页面可能含后加标题、校勘记或编者标点；不要把这些误写成原作者文字。

### 交叉核验库：中国哲学书电子化计划

- 《史记》：<https://ctext.org/shiji/zhs>
- 《资治通鉴》：<https://ctext.org/wiki.pl?if=gb&remap=gb&res=638056>

只在主库段落缺失、异文影响判断或需要二次确认时使用。若两个库文字不同，说明异文，不擅自判定唯一正确版本。

## 检索步骤

1. 用 `case-index.jsonl` 找候选案例及卷次。
2. 打开对应逐卷页。
3. 搜索两个以上 `anchors`；单个名句可能出现在评论、注释或其他段落。
4. 阅读决策前因、实际行动和结果的连续上下文。
5. 只保留能支撑当前论点的最短原文片段。
6. 记录完整书名、卷次、篇名或帝纪纪年、URL。
7. 若论点依赖人物动机，而史料只写行为，标为【推断】。

## 全库兜底检索

当结构化索引只有弱匹配、案例过度集中于同一人物/时代，或用户问题需要索引外样本时：

1. 从现实决策内核提取 2–4 组检索概念，如“屡谏不听 / 去留 / 易将 / 久守 / 受任 / 请退”，不要只搜现代职业词。
2. 在主库总目录和逐卷页中检索；可用限定查询 `site:zh.wikisource.org/zh-hans/史記/卷 关键词` 或 `site:zh.wikisource.org/zh-hans/資治通鑑/卷 关键词` 发现候选卷。
3. 若已知人物或年代，先用总目录确定卷篇，再在卷内查行为、劝谏、选择与结果的连续段落。
4. 为新候选临时填写与索引相同的阶段、原型、约束、选项、已知/未知、结果和代价字段。
5. 只有通过下方证据等级 A/B 的候选才进入正式输出；搜索摘要只用于发现，不用于引证。

索引未命中不等于原书无案例；全库检索仍无强匹配时，才报告“当前未找到足够强的史例”。

## 引证格式

使用：

> **【原文】**“短引文。”——《史记》卷九十二《淮阴侯列传》；[原文页](URL)

或：

> **【原文】**“短引文。”——《资治通鉴》卷六十五，汉纪五十七；[原文页](URL)

同一案例有多段证据时，可分别标注“决策前”“行动”“结果”，不要拼接成一段伪原文。省略中间文字时使用省略号，并确保不改变原意。

## 证据等级

| 等级 | 条件 | 允许的写法 |
| --- | --- | --- |
| A | 主库逐卷页已核验，前后文完整 | 可短引并作有限解释 |
| B | 主库与交叉库均定位，但存在不影响主旨的异文 | 可短引，注明异文 |
| C | 卷篇已定位，但当前无法打开或定位原句 | 只可释义；写“原文未复核” |
| D | 仅有二手材料或模型记忆 | 不得作为正式案例证据 |

正式输出优先使用 A/B。若关键案例只有 C，降低置信度并说明。

## 禁止事项

- 不伪造古文、卷次、人物对白、心理活动或司马光/司马迁的评论。
- 不把后世成语、演义情节、影视台词当作两书原文。
- 不把索引中的 `summary`、`anchors` 或 `cost_hints` 直接当成已核验事实。
- 不用现代二手文章代替原文出处。
- 不为了得到整齐的“三正一反”而保留弱相关案例。

## 史料局限

《史记》《资治通鉴》都经过作者选择、叙事压缩和价值判断。史书记录的“选项”通常不完整，沉默者、普通人和失败路径的材料尤其稀薄。把作者评论单独标记为【史家评】，不要把它等同于可观察事实。
