# 决策内核与标签

只使用下列英文标签调用检索脚本；对用户输出时改写为自然中文。标签描述的是因果结构，不是故事主题。

## 决策阶段 `stage`

| 标签 | 含义 | 核心问题 |
| --- | --- | --- |
| `choose` | 明确选择 | 已有 A/B/C，哪项在当前证据下占优？ |
| `explore` | 探索方向 | 缺候选项或现实样本，下一步如何买信息？ |
| `wait` | 等待时机 | 等待会增加筹码，还是只让窗口流失？ |
| `exit` | 退出止损 | 旧路径是否仍产生复利、信息或选择权？ |
| `scale` | 放大重仓 | 正反馈是否可重复，是否值得增加不可逆投入？ |

## 决策原型 `archetypes`

| 标签 | 结构含义 |
| --- | --- |
| `platform-fit` | 能力与平台是否匹配，环境能否放大能力 |
| `option-value` | 当前动作会扩大还是压缩未来选择权 |
| `timing-window` | 价值取决于时机、触发器与窗口关闭速度 |
| `information-quality` | 决策取决于信号质量、反对意见和信息过滤 |
| `feedback-loop` | 是否能获得真实、快速、可归因的反馈 |
| `trust-legitimacy` | 克制、承诺与程序如何换取长期信任或正当性 |
| `reputation` | 声誉是资产、约束还是短期噪音 |
| `alliance` | 合作、结盟与共同利益是否稳定 |
| `coalition-stability` | 多方联盟会否因分配、恐惧或背叛而崩解 |
| `power-asymmetry` | 对方掌握规则、资源或惩罚权 |
| `temporary-leverage` | 议价权来自短期危机，能否转为长期资产 |
| `talent-recognition` | 能力是否被识别、采用、授权和承担结果 |
| `delegation` | 选人与授权、专业判断与控制之间的关系 |
| `succession` | 继任、角色交接与新阶段利益重排 |
| `reform-change` | 改革、守成与系统扰动的取舍 |
| `commitment` | 承诺装置、沉没成本与退出难度 |
| `escalation` | 是否把局部优势或冲突升级为全局投入 |
| `sunk-cost` | 继续投入是否只是为证明过去没有错 |
| `negotiation` | 交换、底线、筹码与可验证承诺 |
| `execution` | 好方向能否被组织、资源和节奏真正执行 |
| `conflict-avoidance` | 退让是在保护大局，还是回避必要冲突 |
| `concentration-risk` | 单点下注、资源集中与失败承受能力 |
| `path-dependence` | 早期选择如何锁定后续路径与依赖 |
| `principal-agent` | 执行者、顾问或平台的利益与决策者不一致 |
| `identity-status` | 面子、身份、地位如何扭曲收益与退出判断 |

## 约束 `constraints`

| 标签 | 含义 |
| --- | --- |
| `low-information` | 关键事实未知或无法直接观察 |
| `low-feedback` | 行动与结果相隔太远，难以学习 |
| `low-autonomy` | 缺少问题定义权、判断权或执行权 |
| `time-pressure` | 不行动本身会产生损失 |
| `irreversible` | 一旦行动难以撤回 |
| `resource-scarcity` | 资金、时间、人力或注意力紧张 |
| `power-asymmetry` | 他方掌握规则和惩罚权 |
| `reputation-at-stake` | 公开承诺、身份或社会评价影响退出 |
| `coalition-dependent` | 结果依赖多个参与者持续合作 |
| `principal-agent` | 信息提供者或执行者有自身利益 |
| `winner-take-all` | 竞争收束后，中间状态难以长期维持 |
| `temporary-leverage` | 当前优势可能随危机结束而消失 |
| `path-dependence` | 过去投入或制度使转向困难 |
| `hostile-environment` | 环境会惩罚试错、异议或暴露弱点 |
| `repeated-failure` | 已有多轮负反馈或模型失效证据 |
| `mandate-change` | 共同目标或角色授权已经改变 |
| `trust-deficit` | 合作双方缺可信承诺或历史信用 |
| `multiple-fronts` | 同时存在多个相互影响的风险源 |
| `moral-cost` | 行动会产生难以外包的伦理负担 |

## 可逆性

- `high`：能低成本撤回，且不会明显伤害未来选择权。
- `medium`：可撤回，但会损失时间、金钱、关系或声誉。
- `low`：会造成长期锁定、重大伤害、法律后果或不可恢复的关系变化。

## 反馈强度

- 弱：浏览、点赞、礼貌认可、一次性情绪兴奋。
- 中：认真追问、重复使用、主动引荐、稳定改善。
- 强：持续付费、重复合作、委托更重要问题、可复现结果、对方承担真实成本。

## 代价账本

### 显性代价

- `money`：现金、收入、资产。
- `time`：等待、机会窗口、恢复期。
- `position`：职位、权限、资格、地理位置。
- `people`：人力、健康、伤亡或照护负担。
- `reputation`：可直接观察的信用和公共评价。

### 隐性代价

- `optionality`：未来选择空间缩小。
- `dependency`：对单一平台、关系人或资源形成依赖。
- `lock-in`：退出成本随时间上升。
- `trust`：关系中的信任、可预测性与合作意愿下降。
- `information`：失去继续学习、比较或听到坏消息的能力。
- `precedent`：本次例外变成以后必须重复的规则。
- `attention`：高摩擦事务吞噬判断与创造力。
- `identity`：身份绑定后难以承认路径失效。
- `moral`：羞耻、内疚、伤害他人或价值冲突。
- `recovery`：失败后的心理、身体和关系修复成本。

## 匹配规则

至少共享“阶段 + 两个原型”或“阶段 + 一个原型 + 两个约束”，才称为强结构相似。只有人物、行业、性别、成败或一句名言相似，不算结构相似。

优先寻找一对分界案例：表面动作相反，但底层目标相同；或表面动作相同，但因信息、权力、窗口、可逆性不同而结果相反。
