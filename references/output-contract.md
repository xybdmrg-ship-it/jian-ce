# 输出契约

## 深度模式

### 先说结论

用 2–4 句话说明：用户真正面对的决策、当前更像哪一阶段、现有证据倾向哪类动作，以及什么条件会令结论反转。

### 1. 决策内核

用紧凑表格列出：

| 项目 | 内容 |
| --- | --- |
| 真正目标 | 不是表面动作，而是用户想换取的结果 |
| 现实选项 | A/B/C；没有清晰选项时写“需探索” |
| 约束 | 时间、资源、权力、责任、边界 |
| 当下已知 | 已有事实与反馈 |
| 最大未知 | 最可能改变结论的变量 |
| 可逆性 | 高/中/低及原因 |
| 决策阶段 | 明确选择/探索/等待/退出/放大 |

### 2. 历史匹配总览

先用表格说明为什么选择这些案例：

| 案例 | 共享内核 | 关键差异 | 用途 |
| --- | --- | --- | --- |
| 主案例 | 2–3 个结构变量 | 不可忽略的差异 | 支持/限制某条判断 |
| 反例 | 与主案例共享的结构 | 导致相反结论的分界变量 | 防止单向类比 |

### 3. 案例卡

每例使用同一结构：

#### 案例名——一句话决策命题

- **决策点**：何时、谁、必须决定什么。
- **当时选项**：列出 2–4 个当时可行选项。
- **当时可知 / 未知**：分开写。
- **判断与选择**：用【史载】【史家评】【推断】区分。
- **结果**：近期 / 中期 / 长期。
- **显性代价**：直接损失或投入。
- **隐性代价**：选择权、依赖、信任、信息、先例、身份、道德等。
- **未选路径**：仅在有意义时写【反事实】。
- **与你的相似 / 不同**：各至少一条。
- **可迁移边界**：什么条件下有效，什么条件下失效。
- **原文出处**：短引文 + 书名卷篇/纪年 + 原文链接 + 证据等级。

不要让单张案例卡膨胀成传记。每个字段只保留与当前决策有关的信息。

### 4. 跨案例规律

只提炼在多个案例中重复出现、且能写出边界的规律。格式优先使用：

> 若 X 与 Y 同时成立，动作 A 更可能占优；若 Z 出现，结论转向 B。

同时写出：

- 真正分界变量；
- 哪条证据最脆弱；
- 是否存在幸存者偏差或史家叙事偏差。

### 5. 你的情景推演

至少比较三条路径：行动、延后取证、退出/替代方案。使用：

| 路径 | 最佳情景 | 基准情景 | 最坏情景 | 可逆性 | 早期信号 |
| --- | --- | --- | --- | --- | --- |

如果用户只有一个模糊方向，把路径改成 1–3 个现实实验，不虚构终局职业或关系答案。

### 6. 当前建议

给出：

1. 当前证据更支持的动作；
2. 结论反转条件；
3. 最值得补的一条证据；
4. 一个 7–30 天、可停止、能获得真实反馈的动作；
5. 继续 / 转向 / 停止的可观察阈值。

### 7. 风险提醒

至少覆盖：

- 类比错位风险；
- 结果偏差与幸存者偏差；
- 古今制度和伦理差异；
- 用户最可能忽略的隐性代价；
- 当前判断的置信度。

## 简版

保持五段：

1. 决策内核；
2. 两个主案例；
3. 一个反例；
4. 分界变量与结论；
5. 下一步和风险。

即使简版也不能省略卷篇、原文链接、显性/隐性代价和反例。

## 语言要求

- 先判断，后讲故事。
- 用条件句代替格言。
- 不堆古文；每段原文只为一个明确论点服务。
- 不用“历史告诉我们”作为无边界结论。
- 明确说出不确定性，但不要用空泛的“因人而异”逃避判断。
